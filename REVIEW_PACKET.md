# 2. Project Overview

Yuddhabhumi VR is a real-time VR strategy card game inspired by ancient Indian warfare. Players deploy character cards, manage resources, and engage in tactical combat within a fully immersive VR environment.

The project includes gameplay systems, AI combat, card mechanics, UI, audio, progression, tutorial flow, and Meta Quest integration.
